# 用途

Barbara 每月初调用此技能，完成当月故事官积分的自动统计，无需逐人手动核对。技能将：
1. 从故事官 Teams 群读取上月内容链接
2. 从月度会议参会记录中识别出席者
3. 向各故事官发 Teams 私信，确认达到阅读量加成门槛的帖子
4. 汇总全员积分，生成月度报告

# 积分规则

## 基础积分

| 内容类型 | 积分 | 识别方式 |
|---|---|---|
| 原创长图文（≥800字） | 30分/篇 | 微信公众号、LinkedIn 长文链接 |
| 原创短图文（＜800字） | 20分/条 | 小红书、抖音图文链接 |
| 原创视频 | 40分/条 | B站、视频号、抖音视频链接 |
| 转发 + 个人原创点评 | 10分/条 | 群消息中含转发链接且附有文字说明 |
| 出席月度分享会 | 10分/次 | 会议参会记录（Barbara 有组织者权限） |
| 有效简历推荐 | 5分/份 | Barbara 手动录入 |
| 有效业务线索 | 100分/个 | QS 团队确认后，Barbara 手动录入 |

## 影响力加成（Impact Bonus）

按单篇最高阅读量，档位不叠加，取最高档：

| 单篇阅读量 | 额外加分 |
|---|---|
| ≥ 1,000 | +30分 |
| ≥ 5,000 | +50分 |
| ≥ 20,000 | +100分 |

## 重要规则
- 只有带 **#storyteller故事官** 标签的内容才计入积分
- 纯转发不计分，必须附原创点评
- 阅读量加成档位不叠加，取最高档
- 荣誉奖励不扣积分；推流基金兑换扣减 200 分

# 执行步骤

## 第一步：获取基本信息
Barbara 启动时提供：
- 统计月份（如：2026年9月）
- 月度会议 Teams 链接
- 各故事官历史累计积分（可选，如有上月汇总表）

**故事官 Teams 频道已固定**：
- 频道名称：SAP故事官俱乐部
- Teams 对话 ID：`19:n7ITM7itiS8gzxKBbj3k8CXMALgnRxsnOK_sjkveIeY1@thread.tacv2`
- 使用 `teams_web_messages` 工具，传入此 ID 读取频道消息

## 第二步：读取频道消息
- 调用 `teams_web_messages`，对话 ID 为 `19:n7ITM7itiS8gzxKBbj3k8CXMALgnRxsnOK_sjkveIeY1@thread.tacv2`，设置 `since` 为统计月份第1日、`until` 为月末
- 提取所有含链接的消息，按发件人（故事官姓名）分组
- 过滤带有 **#storyteller故事官** 标签的内容
- 识别链接平台类型（微信/小红书/B站/LinkedIn/抖音）
- B站链接自动调用公开 API 获取播放量

## 第三步：查询会议参会记录
- 通过 Teams 会议链接查询参会名单（Barbara 作为组织者有权限）
- 记录出席故事官名单，每人 +10 分

## 第四步：发私信确认阅读量
对每位故事官，通过 Teams 私信发送：

> 你好！本月你在故事官群共提交了 X 条内容，感谢你的贡献！
>
> 已识别内容：
> - [链接1] 类型：长图文，基础 30 分
> - [链接2] 类型：视频，基础 40 分
>
> 如有单篇阅读量超过 1000 / 5000 / 20000 的帖子，请回复对应链接和阅读量，我们将为你加算影响力加成。
>
> 请在 [截止日期] 前回复，逾期不计加成。谢谢！

## 第五步：汇总积分报告
收到故事官回复后（或截止日期后），汇总生成月度积分报告。
