# SAP Storyteller Skills

AI skills for SAP Storyteller (故事官) program — helping SAP employees create, review, and track social media content.

## Skills

| Skill | Description |
|---|---|
| [storyteller-content-reviewer](skills/storyteller-content-reviewer/SKILL.md) | Pre-publish compliance review against SAP communication guidelines |
| [storyteller-score-calculator](skills/storyteller-score-calculator/SKILL.md) | Calculate points based on the Storyteller incentive rules |
| [storyteller-topic-suggester](skills/storyteller-topic-suggester/SKILL.md) | Generate topic ideas and platform-specific hooks to overcome creative blocks |

## Install

```bash
npx skills add <your-github-username>/storyteller-skills
```
